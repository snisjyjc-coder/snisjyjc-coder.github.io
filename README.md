## 1. 깃허브에 올리는 방법

브라우저만 있으면 됩니다.

1. [github.com](https://github.com) 가입 후 로그인
2. 오른쪽 위 `+` → **New repository**
3. **Repository name**에 `아이디.github.io` 입력
4. **Public** 선택 → **Create repository**
5. **uploading an existing file** 링크 클릭
6. `index.html` 과 `images` 폴더를 **한꺼번에 끌어다 놓습니다**
7. 아래 **Commit changes**

1~2분 뒤 `https://아이디.github.io` 로 열립니다.

> 폴더가 통째로 올라가지 않으면, 먼저 `index.html`만 올린 뒤
> **Add file → Create new file** 을 눌러 이름 칸에 `images/hero.jpg` 처럼
> 슬래시를 넣어 폴더를 만드셔도 됩니다.

## 2. 한 달에 한 번 하실 일 — 이달의 소식 올리기

매달 고치실 곳은 **딱 한 군데뿐**입니다. 파일 안에 네모 테두리로 크게 표시해 두었습니다.

### 절차

1. 깃허브에서 `index.html`을 누릅니다.
2. 오른쪽 위 **연필 버튼**을 누릅니다.
3. `Ctrl + F` (맥은 `Cmd + F`)로 **이달의 소식**을 검색합니다.
4. 네모 표시 사이의 글자만 바꾸십시오.
5. 맨 아래 **Commit changes**를 누릅니다. 1분 뒤 반영됩니다.

### 고치실 세 부분

**① 이번 달 표시**

```html
<strong>2026년 10월</strong>
<span>10월 1일 올림</span>
```

**② 목회 서신**

`<div class="letter">` 안의 문단입니다. 쓰지 않으실 달에는 `<div class="letter">` 부터 그에 대응하는 `</div>` 까지 통째로 지우셔도 됩니다.

**③ 이번 달 일정**

한 항목은 이렇게 생겼습니다.

```html
<li>
  <span class="d">10월 4일</span>
  <span class="c">
    <strong>성찬 예배</strong>
    <small>주일 낮예배 중에 함께 드립니다.</small>
  </span>
</li>
```

- `10월 4일` 자리에 날짜를 씁니다. `매주 화요일` 처럼 쓰셔도 됩니다.
- `성찬 예배` 자리에 제목을 씁니다.
- `<small>` 안에 한두 줄 설명을 씁니다. 필요 없으면 그 줄을 지우십시오.

**늘리시려면** `<li>` 부터 `</li>` 까지 통째로 복사해 아래에 붙이십시오.
**줄이시려면** `<li>` 부터 `</li>` 까지 통째로 지우십시오.

### 두 가지만 주의하십시오

`<` 와 `>` 로 감싼 부분은 컴퓨터에게 주는 표시입니다. **글자만 바꾸시고 꺾쇠 괄호는 지우지 마십시오.** `<strong>` 을 열었으면 반드시 `</strong>` 로 닫혀 있어야 합니다.

실수하셔도 괜찮습니다. 깃허브는 고친 기록을 모두 남기므로, 화면이 이상해지면 저장소의 **History**에서 이전 상태로 되돌릴 수 있습니다.

## 3. 설교 영상은 자동으로 바뀝니다

**주일설교 재생목록에 영상을 추가하시기만 하면** 홈페이지 설교도 함께 바뀝니다. 파일을 고치실 필요가 없습니다.

연결된 재생목록: `PL0SoWaG8hzbID3Z0vikL1cYEqQQos6T7l`

매주 하실 일은 두 가지뿐입니다.

1. 설교 영상을 유튜브에 올립니다.
2. 그 영상을 `주일설교` 재생목록에 추가합니다.

### 반드시 한 번 확인해 주십시오 — 재생목록 정렬

재생목록은 기본적으로 **먼저 추가한 영상부터** 재생됩니다. 그대로 두시면 홈페이지에 오래된 설교가 맨 앞에 나옵니다.

1. 유튜브에서 `주일설교` 재생목록을 엽니다.
2. 목록 위쪽의 **정렬** 또는 점 세 개 메뉴를 누릅니다.
3. **추가된 날짜(최신순)** 을 선택합니다.

한 번만 하시면 계속 유지됩니다.

### 재생목록 공개 범위

재생목록이 **공개**로 되어 있어야 홈페이지에 나옵니다. 일부공개나 비공개면 화면이 검게 나옵니다.

## 4. 첫 화면 배경 사진 바꾸기

지금은 보내 주신 바다 일출 사진이 들어가 있습니다. 흰 글자가 사진 위에 얹히므로 왼쪽을 진하게 덮는 층을 넣어 두었습니다.

다른 사진으로 바꾸시려면 이렇게 하십시오.

1. 새 사진을 `images` 폴더에 올립니다. 가로 2400px, 용량 600KB 이하를 권합니다.
2. `index.html`에서 `Ctrl + F`로 **배경사진**을 검색합니다.
3. `url('images/hero.jpg')` 안의 파일 이름을 바꿉니다.

**글자가 잘 안 보이면** 그 아래 `.hero::after` 안의 소수점 숫자들을 키우십시오. 숫자가 클수록 어두워져 글자가 잘 보이고, 작을수록 사진이 선명해집니다.

**사진의 어느 부분을 보여줄지** 조절하시려면 `background-position:center 62%` 의 숫자를 바꾸십시오. 낮추면 사진 위쪽이, 높이면 아래쪽이 보입니다.

### 사진 고르실 때

첫 화면 글자가 사진 위에 얹히므로 **어둡고 단순한 사진**이 좋습니다. 하늘, 바다, 들판처럼 복잡하지 않은 장면을 권합니다. 사람 얼굴이 크게 나온 사진은 글자와 겹쳐 보기 어렵습니다.

교회에서 직접 찍은 사진이 가장 좋습니다. 인터넷에서 받은 사진은 저작권 확인이 필요합니다.

## 5. 감리교 로고에 대하여

보내 주신 기독교대한감리회 로고에서 **바깥 흰 배경만 지워** 투명하게 만들었습니다. 로고 안쪽의 흰 고리는 그대로 살아 있습니다. 남색 배경 위에 올려도 네모난 흰 상자가 생기지 않습니다.

상단 메뉴와 하단에 들어가 있고, 브라우저 탭에 뜨는 작은 아이콘으로도 쓰입니다.

크기를 바꾸시려면 `index.html`에서 `.mark .emblem` 의 `40px`, `.foot .mark .emblem` 의 `46px` 숫자를 조절하십시오.

## 6. 색 바꾸기

파일 위쪽 `:root { }` 안의 값만 고치면 전체가 한 번에 바뀝니다.

| 이름 | 값 | 쓰이는 곳 |
|---|---|---|
| `--navy` | `#0E2A5C` | 상단 메뉴, 버튼 |
| `--navy-deep` | `#081B3D` | 첫 화면 바탕, 푸터 |
| `--blue` | `#1E5AA8` | 아이콘, 강조 글씨 |
| `--blue-pale` | `#EAF1FA` | 옅은 배경 |
| `--gold` | `#FFC629` | 빛 강조 |

노란색은 어두운 파랑 위에서만 썼습니다. 흰 바탕 위 노란 글씨는 어르신들이 읽기 어렵기 때문입니다.
